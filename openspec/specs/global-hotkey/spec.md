# global-hotkey Specification

## Purpose

定义全局快捷键的注册、冲突处理与重新绑定行为，使用户能在任意前台程序下唤起识别，同时保证注册失败可见、不监听用户的全部键盘输入、不破坏系统通用操作。

## Requirements

### Requirement: 全局快捷键在任意前台程序下生效

系统 MUST 支持注册一个全局快捷键，在本程序不处于前台时仍能响应。

#### Scenario: 程序不在前台时触发
- **WHEN** 用户正在使用其他程序，按下已注册的快捷键
- **THEN** 本程序执行绑定的动作，无需先切换到本程序

#### Scenario: 主窗口隐藏时触发
- **WHEN** 主窗口隐藏在托盘中，用户按下已注册的快捷键
- **THEN** 绑定的动作被执行

#### Scenario: 长按不重复触发
- **WHEN** 用户按住快捷键组合不放
- **THEN** 绑定的动作只被触发一次，MUST NOT 因按键重复而连续触发

### Requirement: 只接收注册的组合键

系统 MUST NOT 监听或接收未注册的按键输入。

#### Scenario: 用户按下其他按键
- **WHEN** 用户在其他程序中正常输入文本
- **THEN** 本程序 MUST NOT 接收到这些按键，日志中 MUST NOT 出现任何按键内容

### Requirement: 注册冲突必须对用户可见

当快捷键因被其他程序占用而注册失败时，系统 MUST 明确告知用户，MUST NOT 静默忽略。

#### Scenario: 组合键被其他程序占用
- **WHEN** 要注册的组合键已被其他程序占用，注册失败
- **THEN** 界面呈现一条可读提示，说明该组合键已被占用以及可以更换组合键，日志记录失败原因

#### Scenario: 注册失败不影响其他功能
- **WHEN** 快捷键注册失败
- **THEN** 程序其余功能正常可用，主窗口内的所有操作不受影响

#### Scenario: 注册失败不抢占
- **WHEN** 要注册的组合键已被其他程序占用
- **THEN** 系统 MUST NOT 夺取该组合键，占用它的程序继续正常工作

### Requirement: 保留组合键不得被注册

系统 MUST 维护一份保留组合键清单，拒绝注册会破坏系统操作或通用编辑操作的组合。

#### Scenario: 尝试注册通用编辑快捷键
- **WHEN** 用户尝试将快捷键设置为通用编辑组合（如复制、粘贴、全选）
- **THEN** 系统拒绝该设置并说明原因，原有快捷键保持不变

#### Scenario: 尝试注册系统组合键
- **WHEN** 用户尝试将快捷键设置为系统级组合（如任务切换）
- **THEN** 系统拒绝该设置并说明原因，原有快捷键保持不变

#### Scenario: 组合键不含修饰键
- **WHEN** 用户尝试将快捷键设置为不含任何修饰键的单个按键
- **THEN** 系统拒绝该设置并说明原因

### Requirement: 快捷键可重新绑定

系统 MUST 支持修改快捷键组合，修改 MUST 立即生效并持久化。

#### Scenario: 成功重新绑定
- **WHEN** 用户将快捷键改为一个可用的新组合
- **THEN** 旧组合被注销并不再响应，新组合立即生效，设置被持久化

#### Scenario: 重新绑定失败
- **WHEN** 用户改用的新组合注册失败
- **THEN** 原组合保持注册且继续生效，界面提示新组合不可用，配置 MUST NOT 被更新

#### Scenario: 重启后沿用
- **WHEN** 用户设置快捷键后重启程序
- **THEN** 程序沿用该组合并重新注册

#### Scenario: 启动时配置的组合键不可用
- **WHEN** 程序启动时配置中的组合键已被其他程序占用
- **THEN** 程序正常启动，状态区提示快捷键未生效及其原因，MUST NOT 自行改用其他组合

### Requirement: 退出时注销快捷键

程序退出时 MUST 注销已注册的全局快捷键。

#### Scenario: 正常退出
- **WHEN** 用户退出程序
- **THEN** 已注册的组合键被注销，其他程序可立即注册该组合

#### Scenario: 退出后重启
- **WHEN** 程序退出后立即重新启动
- **THEN** 快捷键可再次成功注册，MUST NOT 因上次未注销而失败
