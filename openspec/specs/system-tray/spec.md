# system-tray Specification

## Purpose

定义程序在系统托盘中的常驻行为：托盘入口、主窗口关闭后的去向、用户可找到的退出路径，以及托盘不可用时退回前台程序的降级方式。

## Requirements

### Requirement: 托盘图标与菜单

系统 MUST 在托盘区提供图标与菜单，菜单 MUST 至少包含显示主窗口与退出程序两项。

#### Scenario: 程序启动
- **WHEN** 程序启动且托盘可用
- **THEN** 托盘区出现程序图标，悬停可见程序名称

#### Scenario: 通过托盘显示主窗口
- **WHEN** 主窗口处于隐藏状态，用户通过托盘图标请求显示
- **THEN** 主窗口显示并置于前台

#### Scenario: 通过托盘退出
- **WHEN** 用户在托盘菜单中选择退出
- **THEN** 程序释放全局快捷键等系统资源后完整退出，托盘图标消失

### Requirement: 主窗口关闭行为可配置

关闭主窗口的行为 MUST 可配置为隐藏到托盘或退出程序。

#### Scenario: 配置为隐藏到托盘
- **WHEN** 关闭行为配置为隐藏到托盘，用户关闭主窗口
- **THEN** 主窗口隐藏，进程继续运行，托盘图标保持存在

#### Scenario: 配置为退出程序
- **WHEN** 关闭行为配置为退出程序，用户关闭主窗口
- **THEN** 程序完整退出

#### Scenario: 首次隐藏到托盘时告知用户
- **WHEN** 用户第一次以隐藏到托盘的方式关闭主窗口
- **THEN** 系统给出一次提示，说明程序仍在后台运行以及如何再次打开，该提示 MUST NOT 在此后每次关闭时重复出现

#### Scenario: 隐藏后进程不退出
- **WHEN** 主窗口隐藏到托盘且没有其他窗口可见
- **THEN** 进程 MUST NOT 因为不存在可见窗口而退出

### Requirement: 退出路径始终可达

在程序常驻后台的任何状态下，用户 MUST 能找到一条退出程序的途径。

#### Scenario: 主窗口不可见时退出
- **WHEN** 主窗口处于隐藏状态
- **THEN** 用户可通过托盘菜单退出程序

#### Scenario: 退出时释放系统资源
- **WHEN** 程序以任意途径退出
- **THEN** 已注册的全局快捷键被注销，实例端点被释放，托盘图标被移除

#### Scenario: 识别进行中退出
- **WHEN** 一次识别正在执行时用户请求退出
- **THEN** 程序正常退出，MUST NOT 出现无响应或崩溃

### Requirement: 托盘不可用时降级为前台程序

当系统托盘不可用时，系统 MUST 退化为普通前台程序，MUST NOT 启动失败。

#### Scenario: 托盘不可用
- **WHEN** 程序启动时系统托盘不可用
- **THEN** 程序正常启动并显示主窗口，记录一条日志说明托盘不可用

#### Scenario: 托盘不可用时的关闭行为
- **WHEN** 托盘不可用，用户关闭主窗口
- **THEN** 程序退出，MUST NOT 隐藏到一个不存在的托盘而使用户无法再次访问程序
