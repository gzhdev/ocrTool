## MODIFIED Requirements

### Requirement: 支持三种图像输入方式

系统 MUST 支持从文件选择、拖放、剪贴板与屏幕区域捕获四种途径载入图像。四种途径载入的图像 MUST 在后续处理中完全等价。

#### Scenario: 从文件选择载入
- **WHEN** 用户通过文件选择对话框选中一张受支持格式的图像
- **THEN** 图像被载入并显示在预览区，成为当前待识别图像

#### Scenario: 拖放载入
- **WHEN** 用户从文件管理器将一张受支持格式的图像拖放到窗口内
- **THEN** 图像被载入并显示在预览区

#### Scenario: 从剪贴板载入
- **WHEN** 剪贴板中存在图像数据，用户执行粘贴
- **THEN** 图像被载入并显示在预览区

#### Scenario: 剪贴板中无图像
- **WHEN** 剪贴板中不存在图像数据，用户执行粘贴
- **THEN** 界面提示当前剪贴板中没有图像，当前图像保持不变

#### Scenario: 从屏幕区域捕获载入
- **WHEN** 用户完成一次有效的屏幕区域选择
- **THEN** 捕获的图像被载入并显示在预览区，成为当前待识别图像

#### Scenario: 捕获图像不经格式校验
- **WHEN** 图像来源为屏幕区域捕获
- **THEN** 系统 MUST NOT 对其执行扩展名与可解码校验——该图像由程序自身生成而非外部文件，格式校验对其不适用
