## ADDED Requirements

### Requirement: 枚举可用模型

系统 MUST 能列出全部可用模型及其可供用户识别的展示名称。

#### Scenario: 存在多个模型
- **WHEN** 模型目录下存在多个描述文件完整的模型
- **THEN** 系统返回全部模型的标识与展示名称，顺序稳定可预期

#### Scenario: 枚举时重新扫描
- **WHEN** 用户在程序运行期间向模型目录放入一个新模型，随后再次请求可用模型列表
- **THEN** 新模型出现在列表中，不需要重启程序

#### Scenario: 枚举不做逐字节校验
- **WHEN** 请求可用模型列表
- **THEN** 系统仅读取描述文件并确认模型文件存在，MUST NOT 对模型文件执行哈希校验

#### Scenario: 存在描述文件不完整的目录
- **WHEN** 模型目录下某个子目录缺少描述文件或声明的模型文件不存在
- **THEN** 该目录不出现在可用模型列表中，并记录一条日志说明其被跳过的原因

#### Scenario: 仅有一个模型
- **WHEN** 模型目录下只有一个可用模型
- **THEN** 系统返回仅含该模型的列表，不因数量为一而报错
