## Purpose

定义用户将图像送入系统的方式与校验规则，保证只有可被识别的图像进入流程，且大尺寸图像不会导致内存或响应问题。

## ADDED Requirements

### Requirement: 支持三种图像输入方式

系统 MUST 支持从文件选择、拖放与剪贴板三种途径载入图像。

#### Scenario: 从文件选择载入
- **WHEN** 用户通过文件选择对话框选中一张受支持格式的图像
- **THEN** 图像被载入并显示在预览区，成为当前待识别图像

#### Scenario: 拖放载入
- **WHEN** 用户从文件管理器将一张受支持格式的图像拖放到窗口内
- **THEN** 图像被载入并显示在预览区

#### Scenario: 从剪贴板载入
- **WHEN** 剪贴板中存在图像数据，用户执行粘贴
- **THEN** 图像被载入并显示在预览区

#### Scenario: 剪贴板中无图像
- **WHEN** 剪贴板中不存在图像数据，用户执行粘贴
- **THEN** 界面提示当前剪贴板中没有图像，当前图像保持不变

### Requirement: 受支持的图像格式

系统 MUST 接受 PNG、JPG、JPEG、BMP、WEBP 格式，MUST 拒绝其他格式并给出提示。

#### Scenario: 受支持格式
- **WHEN** 用户载入上述任一格式的图像
- **THEN** 图像被正常载入

#### Scenario: 不受支持的格式
- **WHEN** 用户尝试载入 GIF、TIFF、PDF、SVG 或其他未列出的格式
- **THEN** 系统拒绝载入并提示格式不受支持，当前图像保持不变

### Requirement: 双重校验

系统 MUST 同时校验文件扩展名与实际可解码性，MUST NOT 仅凭扩展名接受输入。

#### Scenario: 扩展名合法但内容损坏
- **WHEN** 用户载入一个扩展名为 PNG 但内容无法解码的文件
- **THEN** 系统提示图像无法读取，当前图像保持不变，技术细节记入日志

#### Scenario: 扩展名与实际内容不符
- **WHEN** 用户载入一个扩展名被改写但实际为受支持图像格式的文件
- **THEN** 以实际可解码性为准，图像被正常载入

### Requirement: 拖放仅接受单张图像

拖放输入 MUST 只接受单张图像。

#### Scenario: 拖放多个文件
- **WHEN** 用户一次拖放多个文件到窗口内
- **THEN** 系统拒绝该次拖放并提示一次只能处理一张图像，当前图像保持不变

#### Scenario: 拖放非图像文件
- **WHEN** 用户拖放的文件不是受支持的图像
- **THEN** 拖放不被接受，当前图像保持不变

### Requirement: 超大图像等比缩放

系统 MUST 对超出最大边长上限的图像进行等比缩放后再送入识别，上限默认 6000 像素且可配置。

#### Scenario: 图像超出上限
- **WHEN** 用户载入最大边长超过上限的图像
- **THEN** 送入识别的图像被等比缩放至上限以内，实际缩放比例被记录并随识别结果返回

#### Scenario: 预览显示原图
- **WHEN** 图像因超限而被缩放
- **THEN** 预览区显示的仍是原始图像，缩放仅作用于送入识别的副本

#### Scenario: 图像未超出上限
- **WHEN** 用户载入最大边长在上限以内的图像
- **THEN** 图像不被缩放，缩放比例为 1.0

### Requirement: 图像数据全程驻留内存

系统 MUST NOT 为识别流程生成临时图像文件。

#### Scenario: 完成一次识别
- **WHEN** 用户从任一输入方式载入图像并完成识别
- **THEN** 磁盘上未产生任何临时图像文件，图像数据全程在内存中流转
