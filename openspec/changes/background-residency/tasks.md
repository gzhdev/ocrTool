# 任务：后台常驻与系统集成

严格按任务组顺序实施：单实例 → 托盘 → 快捷键 → 开机启动。每组验证通过再进入下一组。

## 0. 前置确认

- [ ] 0.1 确认 `mvp-image-ocr` 已完成
- [ ] 0.2 确认 `screen-region-ocr` 的状态。若已完成，任务 5.1 将快捷键绑定到截图识别；若未完成，快捷键先绑定「显示主窗口」，不阻塞本变更

## 1. 单实例（其余功能的前提）

- [ ] 1.1 实现实例端点，名称由当前用户与程序所在目录共同派生
- [ ] 1.2 实现启动检测：先尝试连接已有端点，连接成功即视为已有实例
- [ ] 1.3 实现陈旧端点清理：连接不上时先移除同名遗留端点再建立监听
- [ ] 1.4 **验证陈旧端点处理**：用任务管理器强制结束进程，随后重新启动，确认能正常启动；连续重复 5 次，每次都能启动
- [ ] 1.5 实现重复启动时激活已有实例的窗口
- [ ] 1.6 验证已有实例分别处于「窗口可见」「最小化」「隐藏」三种状态时，重复启动均能正确置于前台
- [ ] 1.7 验证两个不同目录下的副本可同时运行
- [ ] 1.8 实现检测超时与机制不可用时的降级：仍然启动并记录日志
- [ ] 1.9 验证退出时实例端点被释放
